# 词库处理工具（DictProcessor）

一个用于 Rime 输入法词库处理的跨平台桌面工具，提供差集、交集、上词频、出简不出全、提取全码、出重码号、简词提取等七大功能。基于 Python + Tkinter 开发，支持千万行级数据流式处理。

## 功能特性

| 模式        | 说明                                                |
| --------- | ------------------------------------------------- |
| **差集**    | 保留不在参考文件中的行                                       |
| **交集**    | 保留在参考文件中也存在的行                                     |
| **上词频**   | 在参考文件中查找每行的 key，将匹配值追加到行尾（类似 VLOOKUP），支持按词频数字降序排序 |
| **出简不出全** | 对同一词条的多个编码，仅保留最短编码（简码），删除全码                       |
| **提取全码**  | 出简不出全的反向操作，仅保留最长编码（同为最长的均保留）                      |
| **出重码号**  | 为重复编码自动添加序号后缀（如 `a → a、a2、a3`）                    |
| **简词提取**  | 按正则表达式从词库中提取词条，并按词频排序输出，内置正则生成器                   |
| **词组编码**  | 按照规则给无编码词组生成编码                                    |

## 从源码运行

需 Python 3.8+，仅需标准库，无需安装第三方依赖：

```bash
python DictProcessor.py
```
